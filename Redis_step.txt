STEP 1 - Install Redis in System

Run:
sudo apt update
sudo apt install redis-server

Start Redis:
sudo service redis-server start

Check working:
redis-cli ping

Output:
PONG

----------- For Terminal ------------
After step 1 -> redis-cli

STEP 2 - Create Laravel Project

composer create-project laravel/laravel redisProject
cd redisProject
php artisan serve

STEP 3 - Install Redis in Laravel

Install PHP Redis Extension:
sudo apt install php-redis

Restart Apache / PHP:
sudo service apache2 restart

Install Redis Client (Predis):
composer require predis/predis

STEP 4 — Configure Redis in Laravel

Open .env

Replace/add:

CACHE_DRIVER=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis

REDIS_CLIENT=phpredis
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

Clear config cache:

php artisan config:clear
